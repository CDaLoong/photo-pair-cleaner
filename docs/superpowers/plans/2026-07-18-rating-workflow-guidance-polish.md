# FramePair 评分整理引导与完善实施计划

**状态：** 已完成

**目标：** 完成评分驱动照片工作流的第六阶段，让第一次使用评分整理的用户能顺着“选目录 -> 选模板 -> 改规则 -> 生成计划 -> 确认执行 -> 查看历史”完成任务，并保证窄窗口、页面放大和侧栏收起时仍可操作。

**实施方式：** 在当前 `main` 分支和当前工作区串行完成。每个行为变更先补失败测试，再实现最小改动并运行相关测试。

## 验收标准

- 用户不需要先理解全部字段，就能从空状态直接选一个常见模板开始。
- 评分整理蒙版引导按真实操作顺序覆盖所有关键步骤，且每一步目标在打开引导时存在。
- 页面顶部可以直接查看操作历史数量并跳转到恢复区域。
- 生成计划、执行确认、隔离区/回收站选择及恢复语义不改变。
- 常规桌面、窄窗口、页面放大和左侧栏收起时都没有关键控件溢出或遮挡。
- 前端测试、生产构建、Rust 核心测试及远端 CI 全部通过。
